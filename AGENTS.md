# Repository agent instructions

Read [CONTRIBUTING.md](CONTRIBUTING.md) before making changes.

When preparing or reviewing an npm release, a Changesets version PR, or a change
to released behavior, use the repository's
[release-documentation skill](.agents/skills/release-documentation/SKILL.md).
Check documentation against the actual candidate and report validation limits.
The skill supplements the release workflow; it does not authorize publication,
replace required checks, or require running a release for ordinary edits.

This is a maintainer skill for Weftlet itself. The separately packaged
`templates/context-graph-development/SKILL.md` guides consumer project agents.
