lists added/fixed behavior and relevant compatibility notes. The packages release
as a matching pair. [GitHub Releases](https://github.com/jchewitt/weftlet/releases)

## Unreleased work

The 0.10 candidate adds independent Claude Code and initial OpenCode API
extraction. Shared skill/client onboarding and these guides are in development;
see the [0.10 plan](RELEASE-09-10-PLAN.md) and pending `.changeset` entries in Git.
It has not been published merely because it appears on a branch. Storage retention,
architecture-only packaging and the 2.0 hosted review/AI service remain separate.

## Before upgrading

Read the target changelog for refresh requirements. Keep matching package versions,
retain old snapshots/artifacts, preview work with `hydrate --plan`, and approve any
new model cost before hydration. Query-only improvements may need only new query
pagination; extraction/identity changes can require a new graph and semantic work.
Historical evidence must remain labeled historical. Do not edit cached assertions
or weaken validation to make an old graph pass a newer contract.
