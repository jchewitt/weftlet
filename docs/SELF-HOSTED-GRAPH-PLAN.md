# Self-hosted graph access and exploration for 1.0

The open-source 1.0 release will let a team publish a graph once and inspect the same saved evidence through a viewer, JavaScript or MCP. Local filesystem snapshots remain the default. A portable report remains a static delivery option. Weftlet Cloud is the separate 2.0 product built on these contracts.

| Order | Deliverable | Acceptance |
| --- | --- | --- |
| 1. Versioned reads | A lightweight JavaScript client with TypeScript declarations for catalog, fact, neighborhood and bounded path queries. Use it in the live explorer. The versioned client merged in PR #140. | Install the packed toolkit in another project. Compare full responses and continuation against the local reader. Reject a mismatched snapshot ID or expected digest. |
| 2. Self-hosted service and MCP | A deployable Node artifact with an optional Docker image. Serve an explicitly selected, immutable snapshot without a source checkout or provider login. Let MCP use the service for supported reads, including agent impact queries. Document authentication, project authorization, TLS termination and operating limits before remote deployment. | Use two clients against one service. Compare IDs, directions, citations, authority, coverage, freshness and continuation with the filesystem reader. Test unauthorized requests, project isolation, restarts, and unavailability. |
| 3. PostgreSQL storage | An optional server-side adapter. Configure storage independently from viewer delivery. Import an integrity-checked snapshot under its repository, snapshot and content identity. Publish atomically, handle retries and concurrent imports, and keep the previous generation readable on failure. | Start from an empty database, import and restart, then query the same pinned snapshot. Exercise large payloads, historical IDs, corruption and rollback. Measure import size, peak memory, cold reads and repeated bounded query latency on a TradePilot-sized graph. A repeated neighborhood read should avoid deserializing the entire snapshot. |
| 4. Repository overview | A Sigma overview of domains, workflows and services. Show the saved evidence behind each aggregate. Open an exact node in the focused Cytoscape explorer and preserve the way back. | Locate a downstream service from upstream intent, inspect a source citation and return to the same map position. Bound visible items and disclose coverage at portable-report boundaries. |
| 5. Graph vocabulary | Show node kinds, predicate meanings and direction. Open a cited instance from the selected snapshot when one exists. | Distinguish vocabulary from instance evidence, preserve authority and handle a defined predicate with zero saved examples. |

**Filesystem service progress.** The [bundle reader](VIEWER.md#serve-ci-evidence-from-another-machine) serves one verified generation over loopback or an authenticated HTTPS reverse proxy. The [hosted MCP client](guides/AGENTS.md#use-a-self-hosted-snapshot) adds impact and four graph reads on the same HTTP service. PostgreSQL and consumer-scale deployment qualification follow.

**1.0 qualification.** Use one immutable snapshot for the local viewer, self-hosted viewer and MCP. Follow a product rule to a method, an incoming caller and its citation. Compare complete fact objects and traversal directions, then follow a cross-domain handoff without treating it as a runtime call. Record results at consumer scale. TradePilot can independently replay the 0.15.0 retrieval change now.

**2.0 product.** Managed hosting, organizations and permissions, review/approval, source-adapter write-back, hosted AI credits and billing use the open-source service and storage contracts. Database credentials stay with the service. A self-hosted installation requires no Weftlet Cloud account.
